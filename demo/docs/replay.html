Replaying logs

--replay FILE (alias --dry-run) reads a log from the start, prints alerts, and never sends email, Slack, webhook or sharing reports.

Always use a throwaway state database so your real baseline is untouched:

shellsha256:da85e223176f
sshsentry -c sshsentry.yaml --db /tmp/sshsentry-test.db --replay sample-auth.log

Add a digest

--replay FILE --digest-now also prints a digest for that file:

Your own logs

  • Debian/Ubuntu: /var/log/auth.log; RHEL/Fedora: /var/log/secure. Rotated files work too.
  • journald-only systems: journalctl -u ssh -o short > ssh.log then replay that file.
  • Both classic syslog and ISO-8601 timestamps are parsed, from sshd and newer sshd-session processes.
  • Add --format json for machine-readable output.
Prefer not to install anything? The live demo runs a JavaScript port of the rules in your browser; paste a log, nothing is uploaded.
