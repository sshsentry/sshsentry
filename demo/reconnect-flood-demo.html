What this is and isn't. This is a simulation. The real Nov 13 event was router traffic on the FAA's FTI network, not SSH logins. SSH Sentry reads SSH logs, so it would only see a flood like this if it hit an SSH server SSH Sentry watches. Router addresses here are placeholders, and connection_flood is a proposed rule that SSH Sentry 0.2.0 doesn't include yet. FAA figures come from AeroTime and Axios coverage on Nov 16, 2026.
